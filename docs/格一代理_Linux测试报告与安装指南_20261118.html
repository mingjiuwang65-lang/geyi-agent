二、服务器安装指南（开发照此执行即可）

0. 前置条件

  • 目标机器：Ubuntu/Debian 或 RHEL/CentOS/Rocky，有 root 或 sudo。
  • 能访问 http://10.0.50.199:15889（199 下载服务，内网 HTTP）。
  • 依赖：curl、openssl、tar、ca-certificates（脚本会自动 apt/yum 安装缺失项）。

1. 一键安装（3 条命令）

# ① 下载客户端包（199 下载服务）
curl -fLO http://10.0.50.199:15889/geyi/geYiProxy-linux-client.tar.gz

# ② 校验完整性（可选但强烈建议）——期望输出 OK
curl -fsS http://10.0.50.199:15889/geyi/geYiProxy-linux-client.tar.gz.sha256 | sha256sum -c -

# ③ 解压并安装（默认 30 分钟随机轮换；--minutes 60 可改间隔，范围 5~720）
tar xzf geYiProxy-linux-client.tar.gz && cd geYiProxy && sudo ./install.sh

安装脚本做四件事：① 通过根签名链验证并安装各节点 CA 到系统信任库；② 写入 with-proxy 包装器与 no_proxy 例外；③ 注册空闲时随机轮换的 systemd timer；④ 注册每分钟 CA 验签自愈 cron。

2. 安装后验证

# 直连应不通（000），经代理应通（302/200）
curl -s -o /dev/null -w '%{http_code}\n' --max-time 8 https://www.google.com
source /etc/proxygw/with-proxy 2>/dev/null; curl -s -o /dev/null -w '%{http_code}\n' --max-time 10 https://www.google.com

# 用包装器让任意命令走代理
/etc/proxygw/with-proxy curl -sI https://www.youtube.com | head -1

# 查看当前状态与轮换定时器
systemctl status geyiproxy-rotate --no-pager 2>/dev/null | head -8
cat /etc/cron.d/proxygw_ca_refresh 2>/dev/null

3. 常用运维操作

需求命令 / 方法

4. 常见问题

  • google 仍 000：先确认直连是否也不通（正常）；再 curl -v 看是否 TLS 证书错误——若是 certificate verify failed，说明节点 CA 未装或已漂移，跑一次 /etc/proxygw/ca_refresh.sh。
  • 内网地址访问变慢/不通：检查 no_proxy 是否含内网段（脚本默认已含 10./172.16./192.168./172.17.）。
  • RHEL/CentOS 缺 openssl：脚本会尝试 yum/dnf 安装；离线环境需预先装好 curl openssl ca-certificates。
说明：Development/测试环境请连内网 10.0.50.x 节点。若服务器在无法直连 10.0.50.x 的网络（如云主机），需先打通到节点 15888/15889 的网络可达性——这与客户端无关。
